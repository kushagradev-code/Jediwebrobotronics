# FORGE - HCET Syndicate Tactical Portal

A lightweight, zero-dependency sci-fi Web HUD interface simulating a decentralized covert operations portal.

## Features
- **Command Dashboard:** Live passkey timers, trust tier verification, threat level toggles, and live intel feeds.
- **Galactic Safe Node Map:** Animated radar sweep, constellation routes, and visual telemetry meters.
- **Asterion Codex Chamber:** 5x5 matrix ancient glyph cipher with Dual-Force protocol authentication.

## Built With
- Vanilla HTML5
- Custom CSS3 (Scanline effects, glassmorphism, HUD keyframes)
- Modern JavaScript (ES6)
